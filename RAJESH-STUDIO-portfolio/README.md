# RAJESH.STUDIO

Premium responsive portfolio for Rajesh Studio.

## Files
- `index.html` — complete semantic page
- `styles.css` — responsive red/black/white design system and animations
- `script.js` — navigation, filters, counters, testimonial slider, copy-email, cursor and interactions

## Deploy to GitHub Pages
1. Create a repository (for example `rajesh-studio`).
2. Upload the three files to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save.

## Replace placeholders
- Portfolio artwork is represented with CSS visuals so the site works immediately.
- Replace the `.project-image` backgrounds with real project images, or add `<img>` elements.
- Replace video placeholder cards with local MP4 files, YouTube, or Vimeo embeds.
- Replace `#` social links with real Instagram/TikTok/Behance/Dribbble/LinkedIn URLs.
- Add a real favicon and OG image when available.
